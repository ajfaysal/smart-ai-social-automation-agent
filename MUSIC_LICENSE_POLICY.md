# Copyright-Safe Mood Music Policy

## Goal
DubStudio AI may add a subtle background music bed based on the detected scene mood, without importing an unverified third-party recording.

## Allowed sources
1. **Original procedural music generated by the application** — default safest mode; no third-party recording is bundled.
2. **Verified public-domain / explicitly royalty-free library tracks** — only when the track's license, source URL, and attribution requirements are stored in the project metadata.

## Never do
- Do not scrape random "no copyright" YouTube uploads.
- Do not assume a track is copyright-free because a website labels it that way.
- Do not add a library track unless its license can be verified.
- Do not claim that a third-party track is universally claim-free; platform Content ID and territorial rights can still vary.

## Mood matching
The dubbing director's emotion labels can map to: neutral, happy, laughing, sad, crying, angry, scared, surprised, romantic, whispering, shouting, and apologetic.

Music is always ducked beneath dialogue so speech remains intelligible. The background bed must never replace or reintroduce the original dialogue stem.

## Metadata requirement
Every automatically selected external track must carry:
- title
- creator
- source URL
- license name
- license URL
- attribution text, if required
- retrieval date

The final manifest should distinguish `original_background`, `procedural_original`, and `verified_external_library` so the user knows exactly what audio was used.
